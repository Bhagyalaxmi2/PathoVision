# Model Card: PathMNIST ResNet-18 Pilot

## Summary

This card documents the optional tile classifier included in PathoVision. It is a small, reproducible transfer-learning engineering pilot using the official PathMNIST benchmark. It is intended for educational and research software demonstrations only. It is not a diagnostic model and is not validated for clinical use.

## Model details

| Item | Value |
| --- | --- |
| Model | torchvision ResNet-18, initialized with ImageNet pretrained weights |
| Task | Single-label classification of small colorectal histology patches |
| Input | RGB, resized to 28 × 28 pixels and normalized with ImageNet channel statistics |
| Output | One of nine PathMNIST tissue classes; softmax scores are uncalibrated model scores |
| Fine-tuning | All ResNet-18 parameters; AdamW, learning rate 0.0001, cross-entropy loss |
| Pilot training | 3 epochs, batch size 64, seed 42, CPU run; horizontal and vertical random flips |
| Checkpoint selection | Highest macro F1 on the 2,000-example validation subset (selected epoch 3) |
| Evaluation | Official 7,180-example test split, evaluated once after checkpoint selection |

## Data

PathMNIST is part of MedMNIST v2. It provides 28 × 28 RGB patches from colorectal histology in nine classes: adipose, background, debris, lymphocytes, mucus, smooth muscle, normal colon mucosa, cancer-associated stroma, and colorectal adenocarcinoma epithelium.

The pilot used 12,000 of the 89,996 official training examples and 2,000 of the 10,004 official validation examples, selected reproducibly with seed 42. The complete official test split of 7,180 examples was used for the reported test metrics. No new patient cohort was collected. The raw dataset and trained checkpoint are local artifacts and are excluded from Git.

PathMNIST is distributed under CC BY 4.0. Please cite the MedMNIST v2 paper and the source PathMNIST study when reusing the benchmark or reporting results:

- Kather et al., *Deep learning can predict microsatellite instability directly from histology in gastrointestinal cancer*, Nature Medicine (2019), PathMNIST source study, [doi:10.1371/journal.pmed.1002730](https://doi.org/10.1371/journal.pmed.1002730).

## Pilot results

| Split | Samples | Accuracy | Macro F1 |
| --- | ---: | ---: | ---: |
| Validation subset | 2,000 | 0.878 | 0.878 |
| Official held-out test | 7,180 | 0.853 | 0.808 |

These are results from one short run on a training subset. They are not full-data benchmark or clinical performance claims. The gap between test accuracy and macro F1 indicates that aggregate accuracy alone does not describe class-level behavior; consult the per-class metrics and confusion matrix generated by the training script for more detail.

## Intended use

- Demonstrate a maintainable PyTorch fine-tuning and inference path in a portfolio project.
- Explore model predictions on the benchmark's small, labeled image patches.
- Support software-engineering and model-evaluation discussions.
- Dashboard predictions are limited to the held-out PathMNIST patch demo; the weights are not applied to user uploads or whole-slide images.

## Out-of-scope use

- Diagnosis, screening, triage, treatment selection, or any patient-care decision.
- Patient-level conclusions, calibrated risk estimates, or clinical whole-slide inference.
- Claims of robustness across hospitals, populations, scanners, stains, or specimen preparation methods.

## Limitations and risks

- The input patches are only 28 × 28 pixels and discard much of the cellular and architectural detail present in high-resolution pathology images.
- Only a subset of the available training and validation data was used, and this is one short CPU pilot rather than a model-development study.
- The benchmark does not establish external or prospective generalization. Performance may change substantially with institution, scanner, staining, prevalence, artifacts, or data handling.
- Softmax output is not calibrated uncertainty. A confident score can still be wrong.
- Errors may be uneven across classes; macro F1 and per-class metrics should be reviewed alongside accuracy.
- The accompanying tissue mask is a separate color heuristic and is not a learned segmentation model.
- The optional whole-slide path analyzes an overview and a bounded sample of up to 512 tiles. This does not establish exhaustive slide-level model performance.
- The dashboard displays patch-level outputs only. It does not aggregate evidence into a patient-level result.

## Reproduction

From the repository root, install the requirements and download the official dataset as described in the README, then run:

```bash
python -m pathovision.train data/medmnist --dataset pathmnist --epochs 3 --patience 2 --image-size 28 --batch-size 64 --max-train-samples 12000 --max-val-samples 2000 --evaluate-test --output models/pathmnist_resnet18.pt
```

The script selects the checkpoint by validation macro F1 and evaluates the held-out test split once. Use patient- or slide-level splits for custom pathology datasets to prevent related tiles from leaking across training and evaluation splits.
